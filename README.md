# 从 0 开始学习 AI 底层（大语言模型方向）

> 适用对象：AI 零基础，会一点编程（或愿意从 Python 学起）
> 最终目标：**真正理解大模型是怎么"造"出来的**，而不只是会调 API
> 参考项目：`../minimind/`（但本计划不局限于它）

---

## 学完能做到什么

- 用大白话讲清楚 ChatGPT 这类模型从**数据 → 预训练 → 微调 → 对齐 → 对话**的完整流程
- 不看教程，用 PyTorch **手写一个 GPT** 并训练出来
- 读懂 minimind 的每一行核心代码，**从零训练一个能对话的小模型**
- 理解 SFT / LoRA / DPO / PPO / GRPO 等后训练方法，能读懂主流论文
- 选一个进阶方向（推理优化 / 训练系统与 GPU / 多模态 / Agent）继续深入

## 学习方法（请先读这部分）

1. **主线只跟一个资源。** 每个阶段都标了 ★主线，其他是"卡住时备查"。最常见的失败方式是囤了 20 门课，每门都只看了开头。
2. **看懂 ≠ 会。** 每个视频都要跟着敲代码；敲完以后**关掉视频再独立写一遍**，写得出来才算掌握。
3. **先跑通，再理解；先整体，后细节。** 所以阶段 0 就让你先和 minimind 聊天，带着"它是怎么做到的"去学后面的内容。
4. **数学够用就好，用到再补。** 不需要先学完一整本线性代数。本计划只列出 LLM 真正用到的数学。
5. **费曼学习法。** 每学完一个概念，在 `notes/` 里用自己的话写下来，假装讲给一个外行听。讲不清楚的地方就是没懂的地方。
6. **善用 AI 当私人助教。** 看不懂的公式、代码、报错，直接贴给 Claude 等 AI 让它逐行解释。但**练习代码要自己敲**。
7. **每阶段末尾有自测题。** 能答出 80% 再进入下一阶段；答不出的回去补。
8. **多做实验。** 改一个参数、删一个组件，看看会发生什么——这是理解深度学习最快的方式。

## 关于你的硬件（Apple M4 / 16GB 内存）

| 阶段 | 本机够不够 | 说明 |
|------|-----------|------|
| 0 ~ 4 | ✅ 完全够 | PyTorch 支持 Apple GPU（MPS 后端），小模型训练很流畅 |
| 5 | ⚠️ 部分够 | 小数据冒烟测试可在本机跑；完整训练建议租云 GPU（单卡 3090 约 2 小时、几块钱） |
| 6 | ⚠️ 部分够 | LoRA / DPO 可本机尝试；PPO / GRPO 需要同时加载多个模型，建议云 GPU |
| 7 | 看方向 | 推理部署可用本机（MLX、llama.cpp）；CUDA 编程必须用 NVIDIA 显卡（云上租） |

免费/低价算力：Kaggle Notebook（每周有免费 GPU 额度）、Google Colab（免费版有 GPU）、AutoDL 等国内租卡平台（3090 约 1~2 元/小时）。
